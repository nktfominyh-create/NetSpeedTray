# NetSpeedTray

Маленькая утилита для Windows: показывает текущую скорость интернета прямо на иконке в системном трее.

## Возможности

- Скорость **загрузки** (сверху) и **отдачи** (снизу) на иконке в трее.
- Только цифры: дроби для значений меньше 10 (`0.1`, `0.8`), целые — от 10 и выше.
- Полные значения и единицы — в подсказке при наведении курсора.
- **Настройки** (правый клик по иконке → «Настройки...»):
  - интервал обновления: 0.5 / 1 / 2 / 3 / 5 секунд;
  - единицы: Мбит/с (как у провайдера) или МБ/с (как в торрентах);
  - цвет цифр: белые или зелёные/оранжевые (загрузка/отдача);
  - сон при полноэкранных приложениях — вкл/выкл.
- **Сон в полноэкранном режиме**: когда на переднем плане полноэкранное приложение или окно
  без границ (игра, видео на весь экран), программа полностью останавливает замеры и
  отрисовку, а при возврате на рабочий стол сразу просыпается.
- Автозапуск при входе в Windows (правый клик по иконке).

## Оптимизация

- Иконка перерисовывается только когда цифры реально изменились — в простое нагрузка на
  процессор практически нулевая.
- Список сетевых интерфейсов кэшируется и обновляется раз в минуту.
- В полноэкранном режиме работа полностью приостанавливается.

## Запуск

Скачай готовый **NetSpeedTray.exe** со страницы
[Releases](https://github.com/nktfominyh-create/NetSpeedTray/releases) и запусти — ничего
устанавливать не нужно.

## Сборка

Требуется только .NET Framework 4.x (уже входит в состав Windows). Собрать можно штатным компилятором C#:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Либо вручную:

```powershell
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe `
  /target:winexe /optimize+ /win32manifest:app.manifest `
  /out:NetSpeedTray.exe `
  /reference:System.dll /reference:System.Drawing.dll /reference:System.Windows.Forms.dll `
  Program.cs
```

## Как это работает

Скорость вычисляется как разница байтовых счётчиков активных сетевых интерфейсов
(`NetworkInterface.GetIPv4Statistics`) между двумя замерами. Полученное значение рисуется
на иконку трея через GDI+ (с 4× сглаживанием). Полноэкранный режим определяется по окну
на переднем плане (покрывает весь монитор и не имеет заголовка).

## Ограничение

Windows 11 убрала поддержку тулбаров в панели задач, поэтому текст рисуется на иконку
в трее (16×16 пикселей при 100% масштабе), а не встраивается прямо в панель задач.
