# NetSpeedTray

Маленькая утилита для Windows: показывает текущую скорость интернета прямо на иконке в системном трее.

## Возможности

- Скорость **загрузки** (сверху) и **отдачи** (снизу) обновляется каждую секунду.
- Значения в **Мбит/с** — как у провайдера и в speedtest.
- На иконке — только цифры (белым цветом), без лишних букв.
- Дроби для значений меньше 10 Мбит/с (`0.1`, `0.8`), целые числа — от 10 и выше.
- Полные значения и единицы — в подсказке при наведении курсора на иконку.
- Автозапуск при входе в Windows (правый клик по иконке → «Автозапуск при входе в Windows»).

## Запуск

1. Собери или скачай `NetSpeedTray.exe`.
2. Запусти его.
3. Правый клик по иконке в трее → «Автозапуск при входе в Windows», чтобы программа стартовала вместе с системой.

## Сборка

Требуется только .NET Framework 4.x (уже входит в состав Windows). Собрать можно штатным компилятором C#:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Либо вручную:

```powershell
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe `
  /target:winexe /optimize+ /win32manifest:app.manifest `
  /out:NetSpeedTray.exe `
  /reference:System.dll /reference:System.Drawing.dll /reference:System.Windows.Forms.dll `
  Program.cs
```

## Как это работает

Скорость вычисляется как разница байтовых счётчиков всех активных сетевых интерфейсов
(`NetworkInterface.GetIPv4Statistics`) между двумя замерами, затем переводится в Мбит/с.
Полученное значение рисуется на иконку трея через GDI+ (с 4× сглаживанием) и обновляется
раз в секунду.

## Ограничение

Windows 11 убрала поддержку тулбаров в панели задач, поэтому текст рисуется на иконку
в трее (16×16 пикселей при 100% масштабе), а не встраивается прямо в панель задач.
